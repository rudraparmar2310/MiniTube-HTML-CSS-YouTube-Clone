# 🎥 MiniTube — HTML & CSS YouTube Clone

A fully responsive **YouTube-inspired front-end clone** built using **HTML5** and **CSS3** only. This project recreates the core user interface of a modern video streaming platform, including a responsive navigation bar, sidebar, video grid, search interface, and channel layout—without using JavaScript, frameworks, or backend technologies.

Designed as a front-end practice project to strengthen HTML and CSS fundamentals, responsive web design, Flexbox, CSS Grid, and modern UI development.

---

## 🚀 Features

- 🎬 Responsive YouTube-style homepage
- 🔍 Search bar with modern UI
- 📂 Collapsible sidebar navigation
- 🎥 Responsive video card layout
- 👤 Channel profile & thumbnails
- 📱 Mobile-friendly responsive design
- 🎨 Clean and modern UI
- ⚡ Pure HTML & CSS (No JavaScript)
- 📏 CSS Grid & Flexbox layout
- 🌙 Professional component-based structure
